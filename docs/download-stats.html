새 설치 파일과 업데이트 파일을 따로 확인해요.

기록을 불러오고 있어요.

기존 확인 사용자—분리 집계 이전 · 직접 확인한 인원
새 설치 파일 다운로드—집계 시작 이후 · 웹 설치용 DMG
업데이트 파일 다운로드—집계 시작 이후 · Sparkle용 ZIP

신규 유입은 ‘새 설치 파일 다운로드’로 확인해요. 같은 사람이 다시 받은 횟수도 포함되므로 실제 신규 설치자 수와는 다를 수 있어요. 기존 3명과 다운로드 횟수를 합쳐 실제 사용자 수로 표시하지 않아요.

집계 기준

분리 집계 시작: —
GitHub 공개 릴리스 파일의 다운로드 횟수에서 시작 당시 횟수를 빼서 집계해요. ZIP을 직접 받은 경우도 업데이트용 파일 다운로드에 포함돼요. 설치 완료·실행 여부나 개인 식별 정보는 수집하지 않아요.

배포 파일을 삭제하거나 교체하면 해당 파일의 누적 기록이 사라질 수 있어요. 이미 공개한 파일은 유지하고 새 버전으로 올려주세요.

앱을 열 수 없다는 안내가 나오나요?

현재는 Apple 공증을 거치지 않은 지인 테스트 버전입니다. macOS에서 실행을 제한할 수 있어요. 이런 경우 표시된 안내를 배포자에게 전달해 주세요.

Python이나 다른 프로그램을 설치해야 하나요?

아니요. 실행에 필요한 Python 런타임은 앱에 포함되어 있습니다. 작업 보상을 사용하려면 Claude Code 또는 Codex의 로컬 사용 기록이 있어야 합니다.

업데이트하면 키운 포켓몬은 어떻게 되나요?

진행 상황은 앱과 별도의 로컬 폴더에 저장됩니다. 업데이트 전 설정에서 저장 파일을 내보내 두면 더 안심하고 교체할 수 있어요. 현재는 새 버전을 다운로드해 앱을 교체하는 방식입니다.

내 작업 내용도 수집하나요?

앱은 맥에 저장된 사용 기록에서 입·출력 토큰 사용량을 집계합니다. 작업 보상 집계는 로컬에서 처리하며, 다운로드 웹사이트에 작업 내용이나 게임 저장 파일을 보낼 필요가 없습니다.
